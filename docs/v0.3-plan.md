# PromptPad v0.3 开发与验收清单

当前主线版本为 v0.2.0。此分支先完成日常使用所需的可靠性改进，验收通过后再决定发布版本号。

## 本轮范围

| 项目 | 验收条件 |
| --- | --- |
| 系统托盘 | 关闭窗口后仍有托盘图标；菜单能显示主窗口；退出前等待写入，草稿未保存时先提示。 |
| 单实例 | 重复启动只聚焦已有主窗口，不产生多个共同写入数据文件的进程。 |
| 数据写入 | 连续修改多个模板并重启后保留最后一次内容；失败时界面提示。 |
| 安全导入 | 格式错误不修改模板库；导入前可查看数量、重复项并选择跳过、覆盖或复制；导入前自动备份。 |
| 编辑草稿 | 切换模板或新建时提示未保存修改；点击“使用”会先保存当前草稿。 |
| 设置 | 开机自启开关反映系统实际状态；随系统启动时停留在托盘；能查看和复制数据目录。 |
| Markdown 往返 | 本应用导出的单模板 Markdown 再导入时，保留标题、标签、变量说明、收藏与置顶状态。 |

## 发布前检查

1. `pnpm test`、`pnpm build` 和 `pnpm tauri build` 完成。
2. 在 Windows 安装包中检查窗口关闭、托盘恢复和退出。
3. 使用真实数据副本检查连续保存、损坏文件提示、导入冲突和自动备份。
4. 开关开机自启后重新打开设置页，确认显示与系统实际状态一致。

## 后续功能候选

- 可选全局快捷键呼出搜索。
- 最近使用和使用次数排序。
- 多行变量、复制前完整预览。
- 从设置页选择或迁移数据目录。

这些功能可在可靠性改进完成后逐项加入。
