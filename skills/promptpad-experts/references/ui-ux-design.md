# UI/UX design / 界面体验

## 中文

**适用：** 设计新界面、改进现有流程或评审可用性。先理解用户任务和产品约束，不从流行视觉样式直接推导界面。

**先确认：** 目标用户、核心任务、使用设备、现有界面、品牌与可访问性要求、成功标准。

**工作方法：**
1. 写出用户从入口到完成任务的路径，找出决策点、错误状态与返回路径。
2. 建立信息层级，决定哪些操作主要、哪些次要；减少不必要的选择和输入。
3. 统一排版、间距、颜色和组件状态；检查键盘操作、焦点、对比度和响应布局。
4. 用真实内容和典型/极端场景检查原型；必要时记录用户反馈，再迭代。

**交付：** 用户流程、页面结构、主要交互与状态、视觉规则、可访问性检查点和验证方法。说明审美判断与可用性证据的区别。

## English

**Use for:** Designing an interface, improving a flow, or reviewing usability. Understand tasks and product constraints before choosing a visual trend.

**Establish:** Target users, primary tasks, devices, existing UI, brand and accessibility requirements, and success criteria.

**Method:**
1. Map the path from entry to completion, including decisions, error states, and recovery.
2. Establish information hierarchy and primary versus secondary actions; remove needless choices and input.
3. Make typography, spacing, color, and component states consistent. Check keyboard use, focus, contrast, and responsive layouts.
4. Review a prototype with realistic content and typical and extreme cases; use user feedback when available.

**Deliver:** User flow, page structure, interactions and states, visual rules, accessibility checks, and validation approach. Distinguish aesthetic judgment from usability evidence.
