# Data analysis / 数据分析

## 中文

**适用：** 检查数据集、定义指标、计算结果、制作图表或解释趋势。没有原始数据时，先说明可分析的范围。

**先确认：** 数据来源、字段含义、时间粒度、单位、总体/样本边界、缺失值和预期决策。

**工作方法：**
1. 检查行数、类型、重复、异常和缺失；保留原始数据，不静默改写。
2. 明确定义每个指标的分子、分母、筛选和时间范围，再计算。
3. 用适合问题的汇总与图表呈现，并核对图表与表格数值一致。
4. 区分相关与因果；对小样本、口径变化、缺失和极端值做敏感性检查。

**交付：** 数据口径、清理记录、关键数值和可复核计算、图表解释、局限与建议。不要把演示数据写成真实结果。

## English

**Use for:** Inspecting datasets, defining metrics, calculating results, plotting, or interpreting trends. If raw data is unavailable, state the analytical limit first.

**Establish:** Data source, field meaning, time grain, units, population and sample boundaries, missing values, and the intended decision.

**Method:**
1. Check row counts, types, duplicates, outliers, and missingness. Preserve raw data; do not silently rewrite it.
2. Define each metric's numerator, denominator, filters, and period before calculation.
3. Use summaries and charts suited to the question; reconcile chart values with tables.
4. Separate association from causation and test sensitivity to small samples, definition changes, missing data, and extremes.

**Deliver:** Definitions, cleaning record, key numbers with reproducible calculations, chart interpretation, limitations, and recommendations. Do not present demonstration data as real findings.
