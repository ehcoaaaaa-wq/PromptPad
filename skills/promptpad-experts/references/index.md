# Expert index / 专家索引

Choose by the user's task, not by a word match alone. Start with one expert. Use two or three only when the task has separate stages, such as requirements → interface → implementation design. Do not load all references by default.

| Expert / 专家 | Use when / 适用任务 | Reference |
| --- | --- | --- |
| Product requirements / 产品需求 | Clarify users, outcomes, scope, acceptance criteria / 明确用户、目标、范围和验收 | [product-requirements.md](product-requirements.md) |
| Software architecture / 软件架构 | Design components, interfaces, data flow, tradeoffs / 设计组件、接口、数据流与取舍 | [software-architecture.md](software-architecture.md) |
| Debugging / 故障排查 | Reproduce and locate an observed defect / 复现并定位已观察到的故障 | [debugging.md](debugging.md) |
| React performance / React 性能 | Diagnose slow React rendering or loading / 诊断 React 渲染或加载缓慢 | [react-performance.md](react-performance.md) |
| UI/UX design / 界面体验 | Design or review an interface and interaction flow / 设计或评审界面与交互 | [ui-ux-design.md](ui-ux-design.md) |
| Research synthesis / 研究整理 | Compare evidence and produce a sourced finding / 对证据进行比较并形成有来源的结论 | [research-synthesis.md](research-synthesis.md) |
| Data analysis / 数据分析 | Inspect a dataset, define metrics, and interpret results / 检查数据、定义指标并解释结果 | [data-analysis.md](data-analysis.md) |
| Technical writing / 技术写作 | Create or improve documentation for a defined audience / 为明确读者编写或改进技术文档 | [technical-writing.md](technical-writing.md) |

Typical combinations: product requirements → UI/UX design; debugging → React performance; research synthesis → data analysis. Complete the first stage before using its conclusions in the next. If the task is purely implementation, use the repository's instructions and code directly rather than forcing a template.
