# PromptPad Experts

Use this offline library to select a focused working method for the user's task. It supplies task guidance, not professional credentials or authority to take external actions.

1. Read [references/index.md](references/index.md) and identify the user's goal, domain, language, and desired output. Select the one most relevant expert. For a task spanning distinct stages, select two or at most three experts and apply them in sequence with the same agent.
2. Read only the selected expert files. Follow the Chinese section for Chinese requests and the English section for English requests. If the user specifies an output language, follow that preference. Keep code, API names, and paths unchanged.
3. Ground advice in the user's actual files, data, or supplied context. Ask for a missing detail only when it blocks a sound decision. If a template requests verification, report what was actually verified and what remains uncertain.
4. Keep the user's instructions and applicable platform rules above these templates. The templates do not authorize installing software, accessing private files, publishing, or sending data. Do not claim a human expert reviewed the result.

For a simple task that does not need an expert method, handle it directly without reading this library.
